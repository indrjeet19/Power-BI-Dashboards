# End-to-End Data Analytics & Dashboard Portfolio

## 🚀 Project Overview
An automated end-to-end data analytics system designed to process high-volume datasets, execute predictive risk-scoring algorithms, and deliver real-time operational insights via an interactive executive dashboard.

## 🛠️ Tech Stack & Tools
* **Programming:** Python (Pandas, NumPy, Script Automation)
* **Database & Querying:** SQL (Relational Storage, Complex Joins, Optimization)
* **Business Intelligence:** Power BI (DAX, Power Query, Data Modeling, Star Schema)
* **Workflow:** Automated ETL pipeline from raw data preprocessing to interactive visualization.

## 📊 Key Features & Architecture
1. **Data Preprocessing & ETL:** Cleaned, validated, and transformed raw multi-thousand-row datasets using Python scripts and Pandas to ensure high data integrity.
2. **Backend Management:** Stored and optimized relational data queries using SQL to manage structured data flow efficiently.
3. **Interactive Power BI Dashboard:** Built dynamic visualizations and complex DAX measures to track key operational KPIs, spot drop-offs, and highlight portfolio vulnerabilities.
